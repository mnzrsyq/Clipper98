## Clipper98 v1.1.2

- Short Clips now requests seven candidates by default, matching a full Monday to Sunday posting cycle.
- Rendered MP4 files carry their YouTube title and description. The upload queue reads these values and can reset edits to the original metadata.
- A shared switch controls the hook on thumbnails and opening motion. The font picker uses fonts installed on Windows and fonts imported into Clipper98.
- The output folder can be emptied from the editor after a confirmation prompt.
- Thumbnail previews reflect the rendered cover and include configurable hook styling.
- FFmpeg downloads use the latest Gyan mirror release, and Smart Crop can use available CPU threads for frame analysis.
